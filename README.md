## 신규 페이지 추가하기

`/pages` 디렉터리에 `.html` 파일을 추가한 후 푸시하면 됩니다.

- 파일은 front matter 없이 순수 html로 작성하면 Jekyll이 손대지 않고 그대로 서빙합니다.
- 자동으로 메인 페이지 하단의 `Pages` 섹션에 카드 형태로 노출됩니다.
- 직접 접근 URL: `https://myeongjh.github.io/pages/파일명.html`

예시는 [pages/sample.html](pages/sample.html) 참고.
